
# Lujain Okour — Personal Portfolio

A personal portfolio website created for Project 1 at Orange Coding Academy.

The website introduces me and presents my education, experience,
skills, projects, references, and contact information.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- Git and GitHub

## Website Sections

- Introduction
- About Me
- Experience
- Qualifications
- Skills
- Projects
- References
- Contact Information

## Features

- Blue and brown colour theme
- Card layouts with rounded corners and shadows
- Responsive layout for smaller screens
- Sticky navigation bar
- Downloadable CV
- LinkedIn, GitHub, email, and phone links

## Projects Presented

### Urban Pulse AI V2
A traffic prediction project using Python, XGBoost,
and feature engineering.

### NLP Question Answering
A question-answering project using DistilBERT
and the SQuAD dataset.

## How to Run

1. Download or clone this repository.
2. Keep the files and folders in their original locations.
3. Open index.html in a web browser.

You can also open the project in VS Code and use Live Server.

## What I Practised

- Organising content using HTML elements
- Styling pages using CSS
- Arranging elements with Flexbox
- Adjusting layouts using media queries
- Linking images and files using relative paths
- Uploading and updating a project using Git
